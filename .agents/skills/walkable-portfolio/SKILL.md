# 街を歩くポートフォリオ

最初に対象プロジェクトの作品台帳・描画・操作処理を特定する。「川辺の制作街」では `dist/projects.js` が作品台帳、`dist/scene.js` が描画、`dist/app.js` が操作、`dist/style.css` がレイアウトを担当する。途中で止まっている場合は、存在するファイルとHTMLからの参照を照合して再開する。

## 建物と作品を結び付ける

1. 作品ごとに変わらないID、作者の担当、制作段階、技術、室内で見せる具体物を決める。実画面、実装に基づく操作デモ、説明用サンプルを来訪者が区別できるよう表記する。
2. 単一の作品レコードから入口マーカー・案内所・作品一覧・展示を生成する。新しい作品にはほかの建物や川と重ならない敷地を割り当て、入口座標を扉のすぐ外の歩ける地面に置く。
3. 店の用途を軒・看板・室内の家具で表す。参考にするのは斜め上から見た街区、歩ける道、場所ごとの表情。実在の地図や作者配布の素材を取り込む場合は出典と個別の利用条件を引き継ぐ。参考元 https://april-zhu.com/pocketcity
4. 建物を入れ替えても戻れるよう、屋外・室内・展示の状態を作品IDで管理する。入室時に入口座標とフォーカス元を記憶し、退出後はその入口の外に戻す。

## 移動と表示

- 描画・ポインターの逆投影・当たり判定に同じワールド座標を使う。この街の投影式は `iso(x,y,z)` にある。CanvasのCSSサイズ、端末のピクセル比、ズームを分けて計算する。
- キーの上・右が画面上の上・右に対応するよう移動方向を変換する。対角移動を正規化し、ウィンドウのフォーカスを失ったら押下状態を解除する。
- キー歩行とタップ経路探索で同じ通行判定を共有する。建物本体・川・室内家具を避ける。橋は両岸につながる通路にする。到達不能な点を押した場合は現在地を維持する。
- 道を押すとそこへ歩き、建物を押すと入口へ向かう。入口の「入る」と室内の「展示を見る」をHTMLボタンでも用意する。作品一覧から直接展示へ入れる導線を残す。
- テキストとリンクはDOMで表示する。歩行中にフォーカスを奪わず、入退室で見出しを知らせる。動きを抑える設定では長い移動演出を省略する。

## 動作確認

作品ごとに、広場から入口への到達、入室、展示の内容、退出位置を実操作する。作品一覧から同じ展示を開き、ブラウザの戻るも試す。橋の横の水面へ歩いて侵入できないこと、橋を通って両岸を往復できることを確認する。小さいスマートフォン幅とPC幅で、タップ・キーボードの両方を試す。確認できた操作と未確認の操作を引き継ぐ。
