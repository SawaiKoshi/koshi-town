# 川辺の制作街・街区レビュー

[街を開く](review/walk.html) ／ [橋の眺めを理想画像と比べる](review/vista.html) ／ [俯瞰と石橋からの変更前後を見る](review/compare.html)

初回は石橋で「歩く」から始まる。左手のPISOLA、右手のSISTER、その奥の坂の上にゲーム展示館がある。「街を眺める」を選ぶと、同じ街区を川の上から見渡せる。「橋の眺め」を選ぶと、東岸の高台から橋と川越しに街を見る固定の構図になる。歩行中の地点・向き・画角は、ほかのモードから「歩く」に戻ると復帰する。

| モード | PC | タッチ |
| --- | --- | --- |
| 歩く | WASD・矢印で前後左右に歩く。ドラッグで見回し、Q/Eで左右を向く | 方向ボタンを押し続けて歩く。1本指で見回す |
| 街を眺める | ドラッグまたはQ/Eで回転。ホイール・＋/－でズーム。右ドラッグ・Shift＋ドラッグ・WASD・矢印で移動 | 1本指で回転。2本指をそろえて移動。ピンチでズーム |
| 橋の眺め | ドラッグまたはQ/Eで少し見回す。鑑賞中にもう一度「橋の眺め」を押すと元の構図に戻る | 1本指で少し見回す。もう一度「橋の眺め」をタップすると元の構図に戻る |

歩行中は「視点を移す」で石橋・各店先・丘の前庭へ移れる。入口に近づくと現在地に入口名が表示される。

## 景観と撮影条件

石橋を渡るとSISTERとPISOLAの店先で石畳が広がる。橋を渡って左へ折れると幅1.85mの川沿いの小路があり、民家の玄関と小庭の間を抜けて坂道へ合流する。SISTERの裏手からも住宅の横丁を経て丘へ上がれる。各戸の玄関に向かう小径の幅は1.10m。民家57棟は路地に玄関を向け、間口・階高に合わせて切妻、寄棟、片流れ、屋上テラスやパーゴラを組み合わせた。

左岸の民家は住宅路地側に寄せて軒を下げた。川岸から高さ0.29m、0.58m、0.89mの順に石積みの花壇が続く。SISTERを少し奥へ移して正面を石橋へ向け、坂の内側にあった家を住宅地に移した。坂は中央で左に振れてから右に登り、標高8.10mの展示館前庭に着く。

今回の造形では、オリーブの樹冠とヤシの葉を小さな厚い角形で組み、葉の密度と空が抜ける隙間を変えた。花は紫・桃・黄の群れごとに背丈と間隔を変え、石垣から垂れる蔓を重ねている。近景の石積みには欠けた角、深い目地、石ごとの張り出しを付け、石畳も影を落とす立体にした。PISOLAの低い濃色屋根は細かな重ね葺き、SISTERの入口の小屋根は厚みのある角張った丸瓦で描いた。夕日を暖め、軒下と葉の根元の暗さを強めた。

3棟の形・外壁・開口は元の店舗画像に沿っている。理想画像の完全な再現には至っておらず、樹形、花の密度、背景住宅や細部の造形に差が残っている。

## 橋の眺め（採用案B 東岸の高台）

[理想画像と調整前後を比べる](review/vista.html)。2案を比べたうえで、曲がる坂と展示館の正面全体が見える案B「東岸の高台」を採用し、案Aは削除した。「橋の眺め」モードで、南東岸から石橋の東面越しに街を見る。`walk.html#vista` で直接開ける。2案比較時のリンク用に `#vista-b` も同じ構図で開き、`#vista-a` は石橋の歩行開始位置で開く。

| 画面 | カメラ位置 | 注視点 | 縦画角 | 画面のずらし |
| --- | --- | --- | --- | --- |
| 横長（縦横比0.8以上） | (10, 6.2, 32.5) | (-2, 1, -7) | 45° | なし |
| 縦長（縦横比0.8未満） | (6, 12, 25) | (-1.64, 9.91, -3.94) | 84° | 下へ画面の高さの22.9% |

縦長は、見下ろしを4°に抑えたうえで、写す範囲を下へずらしている（建築写真のシフトレンズと同じ。Three.jsの `setViewOffset`）。縦の線をほぼまっすぐに保ったまま、街を画面の中ほどに置ける。

調整前の案Bは、横長が (6.8, 6.8, 31.5) から (-1.8, 1, -7) を画角47°、縦長が (6.8, 8.6, 37) から (-2.2, 1.2, -8) を画角66°で見ていた。高い位置から見下ろすためアーチがほとんど見えず、縦長では空だけの行が画面上部の23.6%を占めていた。

- 横長：カメラを東へ3.2m・後ろへ1m・下へ0.6m動かした。手前の橋のアーチは、1つが完全に見え、2つ目は下端が半分切れる。展示館の正面全体はSISTERの屋根より上に見えたまま。空だけの行は7.8%から7.1%。
- 縦長：9d4cd3d では (9.8, 7, 29.5) から (-0.3, -5.2, -7) を画角84°で見下ろしていた（見下ろし17.9°）。街が画面の25〜47%の細い帯に収まり、下半分は水面・手前の花・左下の土で、縦の線も約6°傾き、PISOLAの左端は画面の端から11pxしかなかった。そこで下の「縦長の構図の候補」の3案を比べ、候補Bを採った。
- 窓の形に合わせた画角：構図はそれぞれの基準の画面（横長1280×800、縦長375×812）で決めている。窓の形が違うときは、PISOLAの全体（左右の軒の端、三角の看板、青緑の柱、2本のヤシの上端）とSISTERの正面（軒、看板、緑のひさし、白い椅子）の要所が画面の端から12px以上内側に入るまで縦画角を広げる。広げるのは90°までで、構図の画角より狭くはしない。要所の座標は `town.js` の `vistaKeep` に、建物と同じ配置の計算で置いている。SISTERの側面の奥の端は切れてもよい。

見回しは左右±0.32、上下±0.18ラジアン（約18°・10°）まで。鑑賞中にもう一度「橋の眺め」を押すと見回しが0に戻る。歩行位置と俯瞰の状態は鑑賞視点に入っても変わらず、戻ると元の場所から再開する。

石橋の側面は段状の箱で、横から見てもアーチに読めなかった。これを3連の楕円アーチに置き換えた。各アーチは径間4.16mで、迫石19個（中央は要石）、暗めの穹窿の裏面、川中の橋脚2基の水切りで構成する。歩行の通路と通行判定は変えていない。街全体の配置がずれないよう、元の橋の色の抽選回数は残している。

夕日と反対側を向く面には、影を落とさない弱い補助光を当てている。1152ea3 では暖色の0.62だったが、日陰が赤く明るくなり陰影が浅くなったため、0.30のやや青寄りの中立色（#dfe4f4）に変えた。PISOLAの軒下にはペンダント照明の光が店先へこぼれる点光源を置き、オリーブとヤシの葉は太陽を背にした面が薄く透ける。

### 縦長の構図の候補

## 動作確認

Windows版Chrome（Intel Iris Xe・D3D11）で単独HTMLを開いた。1280×800ではキーボード、375×812では方向ボタンの模擬タッチで石橋 → SISTER → PISOLA → ゲーム展示館を連続して歩き、3か所で入口名を確認した。

両サイズで、石橋から川沿いの路地を曲がり、民家の玄関の石段まで歩いた。これとは別に、歩行と同じ通行判定で16cm間隔の格子を石橋から探索し、57戸すべての玄関前へつながることを確認した。俯瞰の回転・移動・ズーム後には歩行位置、向き、画角が復帰した。

歩行中と俯瞰回転中に各90フレームを、他のブラウザー検証と同時実行せずに測定した。全条件でフレーム間隔の中央値は16.7msだった。95パーセンタイルは次のとおり。

| 撮影サイズ | 歩行 | 俯瞰回転 |
| --- | --- | --- |
| 1280×800 | 16.8ms | 16.9ms |
| 375×812 | 16.9ms | 16.8ms |

石橋の初期位置で描画される三角形数は、PCで約94万から201万、375px幅で約86万から192万へ増えた。俯瞰の初期位置ではPCが約98万から210万、375px幅が約91万から201万。遠景の花は花穂を少ない立体で表し、石の欠けは店舗付近と橋に限っている。影は静止した街の初回描画時に計算し、PCは4096px、375px幅は2048pxのシャドウマップを使う。

スマホ幅の確認はPC上のタッチエミュレーション。スマートフォン実機とSafariの描画速度は未計測。

### 橋の眺めの確認（2026-11-25・2案の比較時点）

ヘッドレスChrome 157（Intel Iris Xe・D3D11）でChrome DevTools Protocolから実入力を送った。1280×800ではキーボードとマウス、375×812では模擬タッチで、次の順に操作した。石橋から歩いて見回す → 橋の眺め（案A）→ 案B → 見回し → 案Bを再選択して構図に戻す → 歩く → 街を眺めて回転 → 橋の眺め → 街を眺める → 歩く。両サイズで、歩行に戻るたびに鑑賞前と同じ位置・向き・画角になり、俯瞰の回転状態も保たれた。鑑賞中のWキーで歩行位置は動かなかった。案のボタンは、ドラッグ直後のタップでも切り替わる。

描画負荷は、変更前（60cff8f）と変更後を同じ手順で測った。各条件で毎回再読み込みし、20フレーム描いてから180フレームの間隔を測る。歩行の開始位置・案A・案Bの3視点を2サイズで2回ずつ測った。全条件で中央値は16.7ms。20msを超えたフレームは次のとおり。

| 撮影サイズ | 変更前 | 変更後 |
| --- | --- | --- |
| 1280×800 | 76 / 1080 | 136 / 1080 |
| 375×812 | 0 / 1080 | 29 / 1080（歩行の1回のみ） |
