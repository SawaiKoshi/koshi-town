# 川辺の制作街・街区レビュー

このフォルダーの index.html をブラウザーで開く。Three.js r160（0.160.1、MIT）を vendor/ に同梱しており、ビルドや外部配信は不要。WebGLを利用する。

WASD・矢印で前後左右へ歩き、ドラッグで見回す。Q/Eでも左右を向ける。スマホでは画面右下のボタンを押し続けて移動する。「視点を移す」で石橋・各店先・丘の前庭へ戻れる。入口に近づくと現在地の表示が変わる。

添付写真・店舗のイラストを形状の参考にし、外観、看板、家具、植栽は試作用に立体で構成した。石橋の岸から丘の前庭、3棟の入口までがレビュー対象。公開サイトと既存の展示は dist/ にある。

## 石橋からの比較

[変更前後を見る](review/compare.html) ／ [街を歩く（単独で開けるHTML）](review/walk.html)

引き継ぎ時点（`3710798`）には、3棟の外観、橋、坂、前庭、入口までの歩行があった。今回、橋の先を各店の入口で広がる石畳にし、その奥を二度曲がって約4.2m登る道にした。石積みの段花壇、瓦の重なり、軒下の影、夕空を映す窓を加えた。

比較画像は変更前後とも石橋の同じ地点で撮影した。座標は `(-0.65, 2.25334, 22)`、向きは yaw `0.015`、pitch `0.012` ラジアン。PCは1280×800・縦画角60°、スマホ幅は375×812・縦画角78°。各サイズともDPRは1。

Windows版Chromeで単独HTMLを開き、PCはキーボード、スマホ幅は模擬タッチで方向ボタンを押した。両方とも石橋からSISTER、PISOLA、ゲーム展示館へ連続して歩き、各扉の前で入口名が表示された。橋の欄干に向かって歩き続けても川へ出ないことを確認した。スマホ実機の速度とSafariは未計測。

単独HTMLは `python prototype/review/build_walk.py` で通常の試作と同じソースから再生成できる。
