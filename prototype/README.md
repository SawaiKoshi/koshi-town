# 川辺の制作街・街区レビュー

[街を開く](review/walk.html) ／ [石橋の変更前後と俯瞰を比較する](review/compare.html)

初回は石橋で「歩く」から始まる。左手のPISOLA、右手のSISTER、その奥の坂の上にゲーム展示館がある。「街を眺める」を選ぶと、同じ街区を川の上から見渡せる。歩行中の地点・向き・画角は、俯瞰から「歩く」に戻ると復帰する。

| モード | PC | タッチ |
| --- | --- | --- |
| 歩く | WASD・矢印で前後左右に歩く。ドラッグで見回し、Q/Eで左右を向く | 方向ボタンを押し続けて歩く。1本指で見回す |
| 街を眺める | ドラッグまたはQ/Eで回転。ホイール・＋/－でズーム。右ドラッグ・Shift＋ドラッグ・WASD・矢印で移動 | 1本指で回転。2本指をそろえて移動。ピンチでズーム |

歩行中は「視点を移す」で石橋・各店先・丘の前庭へ移れる。入口に近づくと現在地に入口名が表示される。

## 景観と撮影条件

前回レビュー版（`ad75f58`）を比較元にした。石橋の座標は `(-0.65, 2.25334, 22)`、向きは yaw `0.015`、pitch `0.012` ラジアン。変更前後ともPCは1280×800・縦画角60°、スマホ幅は375×812・縦画角78°、DPRは1で撮影した。

川面の反射、岸の岩と木陰、店先の花穂、石積みの目地、木の横張りと軒裏が距離に応じて読めるようにした。PISOLAの三角看板・青緑の柱、SISTERの鎧戸・2枚の緑のひさし、丘の展示館の水平窓と前庭はそれぞれの元画像を参照した。

## 動作確認

Windows版Chrome・Intel Iris Xe（D3D11）で単独HTMLを開いた。PCではマウスとキーボード、375px幅では模擬タッチを使って回転・移動・ズームを行い、歩行復帰前後の座標・回転・画角の一致を確認した。俯瞰の移動キーを押したまま歩行へ戻しても足元は動かなかった。別に、石橋からSISTER、PISOLA、ゲーム展示館へ視点切り替えを使わず連続歩行し、両サイズで3つの入口名を確認した。

描画負荷は同じPCで、歩行中と俯瞰回転中に各90フレームのアニメーションフレーム間隔を測定した。両サイズ・両モードとも中央値16.7ms、95パーセンタイル16.8ms。初期俯瞰の描画はPCで169ドロー・655,812三角形、375px幅で149ドロー・632,778三角形。静止時はカメラや画面サイズが変わるまで再描画しない。スマートフォン実機の速度とSafariは未計測。

`index.html` が通常の入口。`python prototype/review/build_walk.py` で同じソースから単独HTMLを再生成できる。Three.js r160（0.160.1、MIT）を同梱しており、ローカルでWebGLが使えるブラウザーから開ける。
