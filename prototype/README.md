# 川辺の制作街・街区レビュー

このフォルダーの index.html をブラウザーで開く。Three.js r160（0.160.1、MIT）を vendor/ に同梱しており、ビルドや外部配信は不要。WebGLを利用する。

WASD・矢印で前後左右へ歩き、ドラッグで見回す。Q/Eでも左右を向ける。スマホでは画面右下のボタンを押し続けて移動する。「視点を移す」で石橋・各店先・丘の前庭へ戻れる。入口に近づくと現在地の表示が変わる。

添付写真・店舗のイラストを形状の参考にし、外観、看板、家具、植栽は試作用に立体で構成した。石橋の岸から丘の前庭、3棟の入口までがレビュー対象。公開サイトと既存の展示は dist/ にある。

review/ にPC（1280×800）とスマホ幅（375×812）の実描画を3地点ずつ保存した。ローカルChromiumでキーボード入力と模擬タッチ入力を使い、橋から3入口までの連続移動と橋上の通行制限を確認した。スマホ実機の速度・Safariは未計測。
