# 川辺の制作街・街区レビュー

[街を開く](review/walk.html) ／ [俯瞰と石橋からの変更前後を見る](review/compare.html)

初回は石橋で「歩く」から始まる。左手のPISOLA、右手のSISTER、その奥の坂の上にゲーム展示館がある。「街を眺める」を選ぶと、同じ街区を川の上から見渡せる。歩行中の地点・向き・画角は、俯瞰から「歩く」に戻ると復帰する。

| モード | PC | タッチ |
| --- | --- | --- |
| 歩く | WASD・矢印で前後左右に歩く。ドラッグで見回し、Q/Eで左右を向く | 方向ボタンを押し続けて歩く。1本指で見回す |
| 街を眺める | ドラッグまたはQ/Eで回転。ホイール・＋/－でズーム。右ドラッグ・Shift＋ドラッグ・WASD・矢印で移動 | 1本指で回転。2本指をそろえて移動。ピンチでズーム |

歩行中は「視点を移す」で石橋・各店先・丘の前庭へ移れる。入口に近づくと現在地に入口名が表示される。

## 景観と撮影条件

石橋を渡るとSISTERとPISOLAの店先で石畳が広がる。橋を渡って左へ折れると幅1.85mの川沿いの小路があり、民家の玄関と小庭の間を抜けて坂道へ合流する。SISTERの裏手からも住宅の横丁を経て丘へ上がれる。各戸の玄関に向かう小径の幅は1.10m。民家57棟は路地に玄関を向け、間口・階高に合わせて切妻、寄棟、片流れ、屋上テラスやパーゴラを組み合わせた。

左岸の民家は住宅路地側に寄せて軒を下げた。川岸から高さ0.29m、0.58m、0.89mの順に石積みの花壇が続く。SISTERを少し奥へ移して正面を石橋へ向け、坂の内側にあった家を住宅地に移した。坂は中央で左に振れてから右に登り、標高8.10mの展示館前庭に着く。

比較元は前回レビュー版の 8929981。石橋の歩行カメラは座標 (-0.65, 2.25334, 22)、yaw 0.015、pitch 0.012 ラジアン。俯瞰の注視点は (0, 1, -4)、方位角 −0.45、仰角 0.47 ラジアン。各モードで、変更前後のカメラのワールド行列・投影行列・DPRが一致した。

## 動作確認

Windows版Chrome（Intel Iris Xe・D3D11）で単独HTMLを開いた。1280×800ではキーボード、375×812では方向ボタンの模擬タッチで石橋 → SISTER → PISOLA → ゲーム展示館を連続して歩き、3か所で入口名を確認した。

両サイズで、石橋から川沿いの路地を曲がり、民家の玄関の石段まで歩いた。これとは別に、歩行と同じ通行判定で16cm間隔の格子を石橋から探索し、57戸すべての玄関前へつながることを確認した。俯瞰の回転・移動・ズーム後には歩行位置、向き、画角が復帰した。

歩行中と俯瞰回転中に各90フレームを測定し、両サイズ・両モードでフレーム間隔の中央値は16.7msだった。スマホ幅の確認はPC上のタッチエミュレーション。スマートフォン実機とSafariの描画速度は未計測。

`index.html` が通常の入口。`python prototype/review/build_walk.py` で同じソースから単独HTMLを再生成できる。Three.js r160（0.160.1、MIT）を同梱しており、ローカルでWebGLが使えるブラウザーから開ける。
